# 🛠 Selenium & Pytest 학습 저장소

이 저장소는 셀레니움 기초부터 `pytest`를 활용한 테스트 자동화까지의 학습 과정을 기록합니다.
본 저장소는 **AI QA 엔지니어 에이전트**와 **GitHub MCP**를 연동하여 학습 및 에러 대응을 자동화합니다.

---

## 🤖 AI QA 에이전트 운용 규칙 (Agent Rules)

이 저장소는 효율적인 학습과 자동화를 위해 AI 사수(QA 엔지니어)와의 협업 규칙을 정의하여 운용합니다.

<details>
<summary><b>🤖 에이전트 실행 및 워크플로우 규칙 펼치기/접기</b></summary>
<br>

### 1. 실행 및 에러 대응
- **터미널 실행:** 사용자가 특정 클래스 실행을 요청하면 터미널을 통해 즉시 실행합니다.
- **에러 자동 이슈화:** 실행 중 에러가 발생하면 원인을 분석한 후, GitHub MCP를 사용하여 이슈를 등록합니다.
  - *이슈 제목 컨벤션:* `[AI-Autobug] 에러 요약`

### 2. 코드 수정 완료 후 자동화 워크플로우 (순서 엄수)
사용자가 `"코드 수정 끝났어"`라고 선언하면, 백그라운드 터미널 명령어로 아래 단계를 순차적으로 실행합니다.
- **1단계 (문서 자동화):** 수정된 코드를 분석하여 `studyLog.md`에 요약을 추가하고, `challengeLog.md`에 퀴즈를 업데이트합니다. (파일 수정 후 대기)
- **2단계 (코드 커밋):** 수정한 `.py` 파일만 `git add` 하고, `feat: [실습 주제] 코드 작성 완료` 형식으로 커밋합니다.
- **3단계 (문서 커밋):** 업데이트된 `studyLog.md`와 `challengeLog.md` 파일만 `git add` 하고, `docs: AI 학습 요약 및 퀴즈 업데이트` 형식으로 커밋합니다.
- **4단계 (최종 푸시):** 생성된 두 개의 커밋을 묶어서 `git push origin main`을 실행합니다.

### 3. 퀴즈(Challenge) 진행 규칙
- **퀴즈 출제:** 퀴즈 출제 시 GitHub 이슈에 `[Challenge] 퀴즈 제목` 형태로 내용을 생성합니다.
- **자동 채점 및 이슈 종료:** 사용자가 `challengeLog.md`에 답안을 작성한 후 에이전트에게 알리면(`"답변 썼어"` 등), 에이전트가 내용을 확인하여 **피드백을 제공하고 해당 GitHub 이슈를 즉시 Close** 합니다.
</details>

## 📜 Git 커밋 컨벤션 (Commit Convention)

본 프로젝트는 일관된 코드 이력 관리를 위해 아래의 커밋 규칙을 준수합니다.

<details>
<summary><b>💡 커밋 타입 및 예시 펼치기/접기</b></summary>
<br>

| 타입 (Type) | 내용 (Description) |
| :--- | :--- |
| **feat** | 새로운 기능 추가 또는 기존 기능 요구 사항 수정 |
| **fix** | 버그 수정 |
| **build** | 빌드 관련 수정, 모듈 설치 및 삭제 (pip 등) |
| **chore** | 패키지 매니저 설정, `.gitignore` 등 기타 잡무 |
| **ci** | CI(GitHub Actions 등) 관련 설정 수정 |
| **docs** | 문서 수정 (README.md, 주석 등) |
| **style** | 코드 포맷팅, 세미콜론 누락 등 스타일 수정 (로직 변경 X) |
| **refactor** | 코드 리팩터링 (변수명 변경 등 로직 구조 개선) |
| **test** | 테스트 코드 추가 및 수정 |
| **release** | 버전 릴리즈 |

### 📝 커밋 메시지 예시
- `feat: 구글 로그인 버튼 클릭 자동화 스크립트 추가`
- `docs: 요소 찾기 학습 내용 리드미 업데이트`
- `build: pytest 라이브러리 설치`

</details>
